# 发版前代码审查（2026-10-13）

审查基线：主分支 `3d85449`，已包含 PR #85。范围为当前支持的抖音、哔哩哔哩、知乎；检查启动、API 本地访问边界、账号/二维码生命周期、收藏同步、入库、导出、监控与前端异步状态。

## 已修复的问题

1. **全新安装阻断**：`pyproject.toml` 是 1.2.0，`uv.lock` 根包版本却是 1.1.1，启动器的 `uv sync --locked` 会失败。修正两个依赖锁文件的项目版本，为 release-please 添加锁文件更新器；CI 改用 `--locked`，回归测试检查发布版本与更新配置。
2. **取消后的迟到写入**：入库取消曾在 90 秒后提前结束任务，但处理线程仍可能发布向量。现在保持任务活跃直到消费者退出，并在 Embedding 返回后及完成状态写入前检查取消。测试确认取消期间清空被拒绝、迟到向量不会写入。
3. **同步与入库覆盖**：收藏快照更新正文或分 P 时，可能覆盖正在入库的同一条目。快照发布与任务提交共用互斥锁，存在排队/运行任务时拒绝发布；线程池执行持久化，避免等待锁阻塞事件循环。测试覆盖 queued/running 与结束后恢复同步。
4. **登录状态检查异常中断全部同步**：单个平台状态读取异常会使其他平台无法继续，并丢失已成功平台的响应统计。现在按平台隔离状态读取异常，保留成功结果。
5. **导出重新下载无效**：自动下载后显式下载也被去重。去重只用于自动下载，用户可以重试同一产物。
6. **全库导出数量不一致**：全库选项曾显示当前平台/收藏夹数量。现在使用全库统计，提交范围与显示数量一致。
7. **入库失败没有反馈**：失败终态曾在进度清理后消失。新增八语言失败提示，任务结束后继续显示，重试时清除。
